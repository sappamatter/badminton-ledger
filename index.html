Local backup

Save a copy of the roster and session log as a file on your own device — useful as an offline backup separate from the shared link above, or to move data between links.

On Chrome/Edge, "Save backup" opens your device's file picker so you choose the exact folder and filename. Browsers without that picker (Firefox, Safari) will save it to your usual Downloads folder instead.
